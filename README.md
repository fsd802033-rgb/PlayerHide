/hide <ник> - спрятать игрока. /hide list - скрытые игроки. /hide clear - очищает всех. /hide all - скрывает всех. /hide reload - перезагрузка. Скрытый игрок не рендерится. .Если скрытый игрок телепортируется рядом с клиентом, он остаётся скрытым. Если сущность игрока выгружается и появляется снова, скрытие сохраняется. Никаких крашей при загрузке мира или подключении к серверу.
